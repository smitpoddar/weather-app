🌦️ Weather App
📌 Description

A responsive Weather Application that allows users to check real-time weather updates of any city worldwide. Built with modern web technologies, it fetches live data from a weather API and displays details like temperature, humidity, wind speed, and weather conditions.

🛠 Tech Stack

HTML5, CSS3 → UI design & responsiveness

JavaScript (ES6) → Logic & API handling

React.js (if included) → Component-based UI

Weather API (OpenWeatherMap or similar) → Live weather data

⚡ Features

🌍 Search weather by city name

🌡️ Displays temperature, humidity, and wind speed

☁️ Shows real-time weather conditions with icons

📱 Responsive design (works on desktop & mobile)

🔄 Instant API updates

1.Enter the name of a city in the search bar.

3.Use on desktop or mobile seamlessly.
